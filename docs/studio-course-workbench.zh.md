# Studio 课程工作台

[English](studio-course-workbench.md) | 中文

Better Learning Studio 为每门课自动创建独立 Workspace，目录统一为
`Documents/Better Learning Studio/course/<CourseId>`。最左侧快捷栏提供首页、课程阅读、插件等，设置固定在底部。旁边仅一条上下文左栏：生成时显示课程名，点击课程进入阅读；阅读时同一左栏显示本课文件、搜索和操作，底部“切换其他课程”打开课程选项。中间不再嵌套文件栏。首页恢复当前课的生成 Session；未选课时显示建课表单。折叠左栏后快捷栏仍保留。

收起按钮位于顶部窗口栏；标题放大镜合并搜索与筛选，点击后显示一个输入框。新建课程只留顶部入口，恢复当前课生成只用首页，取消课程行、阅读页和换课菜单的重复入口。内容切换具有轻量动效，适配系统减少动画设置；最左快捷栏的位置、顺序和尺寸保持不变。

原生课程 API 接受课程身份与相对路径，拒绝父级穿越、私有元数据访问及符号链接越界。Markdown 保存比较期望的 SHA-256 版本并保留修改前快照；删除移动到课程本地回收站。重命名先预览链接修改，再核对 token，并在逐文件替换前保存恢复日志。跨文件重命名可恢复，但不是文件系统原子事务。

阅读与 Host 索引共享 `dsh-util-course-document`。编辑使用 CodeMirror 6，56px 单行头部包含前后导航、课程名及阅读/编辑图标，与图标配小字的品牌区对齐，不再重复显示文件路径。阅读历史记录当前课程的文档与标题位置，后退后访问新位置会清除前进分支；离开未保存编辑前仍确认。左、中、右三个区域统一四角16px圆角。文件命令在左树右键菜单。右侧提供当前课程的大纲、反向链接及文件图谱图标；大纲用常展开的嵌套列表和竖向层级线显示从属关系，每个标题保持原跳转命令。右栏手动拖至边缘72px范围内请求课程面板收起，保留宽度偏好供再次展开。图谱的显示与设置见下文。搜索使用 SQLite FTS5 trigram 与短查询字面回退。搜索、反向链接和图谱元信息共享每课可重建索引，未变文件复用已有投影。

已保存 Markdown 的选区会显示讲解、举例、要点、自测、追问。宿主加载对应技能，将技能内容和选区引用提交给本课学习会话。原文快照存入 `.studio/learning`，历史引用可查看快照并跳回匹配版本。

手动修改标为待复核，不重写生成验收凭证。现有生成资源、视觉转写、人工确认与看门狗继续使用。旧的外部课程不静默搬动。本基本版不含社区插件宿主、Canvas、Bases、Sync、Publish、PDF 文本层/OCR 精确引用或完整行内 Live Preview 兼容。

运行不依赖外部 Obsidian。AI 生成与答疑仍需配置模型服务。本轮更新只在本地，不发布到 GitHub 或应用更新渠道。

课程角色固定，生成输入框上方不提供工作区和预设选择，设置不提供Agent预设或代码工作视图。左栏为带展开动效的文件树，顶部四个图标管理创建与全部展开/收起，目录状态在当前课程内保留；文件操作继续使用右键菜单。

阅读目录隐藏旧模板的课程首页、讲义、附件和工作存储；底层文件保留供工作流、引用及附件预览使用。阅读默认打开学习文档，正文明确使用主题的中文无衬线字体栈，代码使用独立字体栈。HTML 注释及包装为行内代码的 BL/BLS 生成定位注释不参与阅读渲染，源码、链接和选区偏移不变。

Studio 的选区浮条使用内置学习技能，开发时在 [`apps/desktop/resources/skills`](../apps/desktop/resources/skills) 维护，打包后随应用放入 `resources/skills`。在 `study-explain`、`study-example`、`study-summarize`、`study-quiz` 和 `study-discuss` 子目录分别放入带 `name` 和 `description` 的 `SKILL.md`，技能名称与子目录一致。当前版本缺少技能时，浮条提示对应路径。

学习助手可以用 `study_skill` 列出或加载内置技能，用 `course_read` 读取本课 Markdown，并用 `study_show` 发布画面。每个 `frames` 条目接受课程相对图片路径 `path` 或自包含 SVG 字符串 `svg`，以及可选画面标签 `label`。单帧直接显示，多帧默认使用 `steps`，通过左右箭头切换离散步骤。`playback` 另提供播放和暂停，`intervalMs` 指定播放间隔。`choices` 用于切换具名情形，`slider` 用于浏览连续参数的采样值。切换控件会显示对应画面，历史对话可重放发布时保存的媒体。

学习助手回答下的笔记图标提供单选/多选，按对话顺序去除完全重复的答案，生成可编辑的 Markdown 整理预览；此步骤保留原答内容，不额外调用模型改写。确认后才写入笔记，每个学习文档首次保存为 `笔记/<文档名>-笔记.md`，后续追加并保留已有正文；新课程不预建笔记文件。同名学习文档的笔记使用源路径摘要区分。宿主投影只提供学习 Session 已结束轮次的最终正文，不导出思考、工具和自动提示词；写入再次核验课程、Session、原文及答案身份。操作 UUID 和内容摘要使同次网络重试不重复追加，冲突保留预览，已有笔记写前留快照。

Studio 输入框使用独立底栏，扩展思考只改变消息滚动范围；首次输入与模式切换保留输入框实例。正文选区保持原生反馈，浮条淡入、文件选中颜色、目录与思考/知识关系折叠使用统一时间和曲线。大纲/目录定位、返回底部使用程序滚动动效；滚轮和触控板保留原生响应，流式回答跟随不反复启动缓动。系统减少动态效果时取消过渡。方案参考 [Radix Collapsible](https://www.radix-ui.com/primitives/docs/components/collapsible) 的受控展开思路，复用现有组件与 CSS Grid 过渡，不引入大型动画运行时。

导入课程保留原目录排版，包括原有讲义和附件目录。切换课程菜单在分隔线下提供唯一“导入课程”入口，弹窗采用与设置一致的方形比例，仅保留虚线拖入区和右上角关闭图标。拖入单个课程文件夹后自动校验至少有一个 .md，再复制到新的课程目录和 Workspace，完成后进入阅读；无文件夹选择和二次确认按钮。导入时显示处理状态，阻止重复拖入和关闭，失败允许重新拖入。原文件不变，不接入来源 .studio 元数据及旧 Session；来源 _工作区归档至 .studio/imported-workspace，另建空的运行工作区。目录联接/符号链接、自导入及超过 20000 项的目录会被拒绝；失败只清理本次新建的目标，复制完成后才发布课程。

阅读、生成回答、学习者消息和学习助手回答使用一致的中文无衬线字体栈与字号。大纲只滚动文档，将标题顶边对齐阅读窗口顶端，也支持末尾标题。品牌为图标与 Better Learning / Studio 两行组合。通用设置提供默认开启并持久保存的“Markdown 美化”，只改变样式，不改解析和源文件。标题、表格与引用排版参考 [github-markdown-css](https://github.com/sindresorhus/github-markdown-css)，继续使用现有 mdast/GFM、KaTeX 与代码渲染。

交付使用 metadata-v1 回执：完整内容验收在清理前完成，打包核对文件和台账元数据，只更新实际改动产物的指纹，移动后检查一次链接并记录结果；后续 packaged 检查不读取 Markdown 正文、不计算全局文件哈希。该机制发现普通变更，不作为密码学完整性证明。已完成旧包可依据留存的通过报告升级，无需恢复中间文件；旧的在生成课程需重跑一次 final。详见[回执升级说明](upgrade-guide/v0.2.1-rc.2/studio-delivery-receipts/guide.zh.md)。

阅读美化支持 Obsidian 的 ==高亮== 及红、橙、黄、绿、蓝、紫六色 emoji 前缀；渲染时隐藏颜色标记，选段仍引用完整原文。Callout 类型和别名使用颜色、图标及柔和底色区分提示、警告、成功、错误与引用，表格表头、标题、引用及代码保持主题层次。样式参考 [github-markdown-css](https://github.com/sindresorhus/github-markdown-css) 及 [Obsidian 官方语法](https://obsidian.md/help/syntax)，继续使用原解析树和安全 React 渲染，关闭美化可撤去颜色装饰。课程源文件保持；原生生成加入下述语义排版处理。

阅读层将完整的 details/summary 结构转换为安全折叠组件，原标记不再显示为代码；嵌套正文继续使用带源位置的 Markdown 解析，任意 HTML 仍不执行。“学习目标、目标与入口”等知识入口保留普通排版，取消整块自动底色，其他现有样式保持；既有总结、练习、易错点分区仍由美化开关控制。普通 note 折叠框仅保留箭头，大纲缩进为原来的四分之三。学习助手的本地引用由所属学习 Session 路由至当前课程阅读器，支持相对路径、工作区内绝对路径、文件 URL、标题及行号；范围外文件、私有工作数据、缺失或歧义目标不打开通用预览。新点击及其他阅读导航使较慢的旧点击失效。

同一文件的大纲、正文链接、学习助手引用及前后历史只发出新的定位请求，保留文档实例和当前滚动位置，再平滑移至目标；重复点击同一标题也生效。切换文件、明确刷新或确认丢弃编辑稿才重建文档。文件内定位使旧选段浮条失效，折叠目标按新的定位请求展开，不依赖重建正文。

原生讲义提交和卡片定稿在内容发布前运行固定的 semantic-v1 语义排版步骤。宿主使用当前模型，在独立、有日志、无工具的会话中请求原文绑定的标注计划和独立审核，每组最多一轮修复。卡片按完整单元分组，其他卡片失败时保留已通过结果。固定语义样式、精确引句、保护范围、条件句检查及讲义8%／卡片6%的荧光上限约束采用范围。Markdown 字节、链接、来源身份、掌握证据及既有内容哈希保持不变。可选的 `.betterlearning/presentation/` 清单在派生关系变化后重新绑定；教学内容绑定失效时使用基础排版。新原生课程要求每个单元都有通过或基础排版终态，旧课的阶段证据保持。卡片元信息和核对区默认折叠，关闭颜色后仍可展开。旧课和导入课程不自动收费重排，外部 Markdown 阅读器仍显示完整原文。打包保留排版目录，不增加全局哈希检查。

表格单元格内双链的别名分隔符在 GFM 分列前受到保护，UTF-16 原文位置不变。表格采用语义表头，长内容换行，多列表格仅在自身横向滚动；引用和选段仍对应原始 Markdown。

阅读工具栏的“文件图谱”图标位于反向链接与学习助手之间，在既有右栏显示当前课程的文件关系。收起右栏图标下方的竖排三点打开设置面板，每次打开时各设置分组全部折叠。展开内容在按钮下方滚动，固定工具栏保持可用；收起右栏后阅读头部为完整工具栏预留宽度。默认隐藏孤立文件和只有自链的文件，连线粗细为0.1、节点间吸引力为0.4；筛选包含搜索、标签、附件、仅已创建笔记及孤立文件开关。颜色组、箭头、文本透明度、节点大小、连线粗细、悬停颜色、向心／排斥／吸引力、连线长度、局部层数与方向、动画回放复用用户提供的独立重建实现。设置按课程保存并保留已存的自定义值，显示过程不调用模型。真实文件节点沿用既有阅读导航；切课、离开阅读或关闭右栏会释放图谱帧、物理Worker和动画计时器。图谱跟随Studio主题，暗色背景显式同步，并尊重减少动画偏好。

设置卡片使用Studio菜单材质、阴影层级、焦点描边及主题滑块。进入与关闭采用快速浮层淡变，分组内容采用统一的高度与透明度展开节奏。收起内容和正在关闭的卡片禁止交互，减少动画偏好会禁用过渡。每次打开仍从全部分组折叠开始。

受认证的图谱投影只包含本课文件路径、标签、时间及本地链接，不包含私有工作文件、隐藏文件或其他课程Session。相同文件目标去重；输入边界为2000份Markdown、64 MiB文本、5000个入图文件和50000个去重文件目标，实际显示至多5000节点。未引用附件不入图。YAML属性双链和别名参与图谱关系，不改变原文链接的改名语义。此视图不改写Markdown或课程生成凭证。

生成、导入后的公开文件变化会在后台准备图谱。已有保存记录时，打开视图先显示上次的关系、位置与视角，再核验源文变化并更新；核验内容未变时保留当前布局。缓存缺失或失效时重建，首次索引仍受课程规模影响。打开文件和创建AI引用继续核验当前原文。

课程读取使用有界缓存和单个排队的Host解析Worker；条件`view`响应省略未变化的树，既有`read`操作保留原始解析契约。私有`.studio/index/course.sqlite`保存原文绑定的元信息与FTS行，更新变化文件并支持Host重启复用。监听通知按受影响路径失效缓存，元信息检查保留为回退；保存、重命名提交与选段引用仍重新校验源版本。解析、缓存与索引不调用模型，不改变生成凭证或课程Markdown。

阅读投影与Host共享安全折叠框规范化；纯阅读不创建隐藏CodeMirror，也不重复解析未变原文，稳定正文跳过无关外壳状态更新。大文档按完整语义块分批挂载，普通文档保留原有结构；邻近公式与折叠答案按需准备，已挂载内容保持。导航先准备目标之前的块与公式高度，再执行一次平滑滚动；原生查找、全选和打印会完成所需内容，同源排版更新不替换草稿。这属于渐进渲染，没有用虚拟阅读回收已选文字。
