- 卡片由主代理按 `_工作区/核心卡片计划.json` 统一写入，不派卡片子 Agent、不自行分配 card_id。

- 卡片出边只有 **canonical K**、**active EX**、**相关讲义 L（章级）**、**前置/后续/关联卡片**；不连来源单元、Path、START、IDX。关系区由脚本渲染，正文内联链接是同一条关系的散文呈现。
- 正文**禁止**手写计划外的任何 wikilink；提及必链实体（前置/后续/关联卡、相关讲义、覆盖知识）的名称或 ID 时**必须**就地附计划字面量，否则报 `UNLINKED_REFERENCE`。引用练习与讲义只用 `links.exercises` / `links.lessons`，不猜标题或路径。
