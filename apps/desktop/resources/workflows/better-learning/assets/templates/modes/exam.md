# 目标模式：考核准备

选择条件：用户明确以某次考试、测评或课程考核为主要目标。

- 路径：完整知识覆盖保留，按有证据的考纲和题型另标主修优先级；未给考纲不虚构“高频必考”。
- 讲解：仍解释概念、方法和条件，示范如何识别任务、选方法、组织答案及检查。
- 练习：先无时限诊断，再混合题和必要的限时练习；文科、语言、技能考核采用对应的作答/表现量规，不能一概变成计算题。
- 反馈：区分知识缺口、选法错误、表达/操作不足和时间分配，针对错因回看；记忆口诀附边界。
- 过关：关键知识与实际题型表现共同判断，模拟成绩不能假装成正式成绩。

只有真实考试要求才能决定评分口径，模板中的题量和时间只是编排参考。
