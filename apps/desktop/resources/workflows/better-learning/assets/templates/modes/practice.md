# 目标模式：实践与产出

选择条件：用户以实际操作、程序、作品、方案或情境任务为主要目标。

- 路径：以可交付小任务递进，明确每项任务需要的知识，必要理论穿插补齐。
- 讲解：从输入、环境和标准出发，展示完整过程，再提供分步支架与独立变式。
- 练习：多数时间用于做、观察反馈、修改和再做；阅读与理论题用于解释选择和定位错误。
- 过关：产出满足明确标准，并有运行、操作、作品或验证证据；无法实际执行时标为设计/文字验证。
- 复习：重做关键任务、排查故障、适应新约束，保存个人错误与修订记录。

选用 performance、code 或 design-project 等实际匹配模块，不因“实践”自动加载全部活动。
