# 活动模块：证明与形式论证

选择条件：目标要求建立命题、证明正确性、反驳推断或分析论证。纯记忆和操作章不自动选用。

嵌入深度解析与示范：

1. 将待证结论写清对象域、量词和条件，分开已知与待证。
2. 展示策略选择：直接、构造、反证、归纳或其他适当方法，并说明为何适合。
3. 用可核对步骤建立论证，每个关键跳步给依据；必要时补一个失败路径。
4. 检验条件能否弱化、结论能否加强，用反例辨析逆命题或遗漏条件。

独立任务：补关键步 → 找错/构造反例 → 迁移证明。参考答案可给多种路径，量规区分结论、逻辑有效、条件完整和关键论据。学生照抄示范不算独立证明。

卡片保留论证骨架、方法触发线索和一个反例，不能只剩结论。验收时抽查逻辑链，形式上有“证明”标题不代表证明完成。
