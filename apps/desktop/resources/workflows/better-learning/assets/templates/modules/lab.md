# 活动模块：实验、观测与田野操作

选择条件：需要测量、实验设计、受控观察、现场记录或操作验证。

嵌入章节：问题/假设 → 可观察指标 → 自变量、因变量与控制 → 仪器/材料条件 → 操作顺序与关键检查 → 原始记录表 → 误差/混淆与处理 → 证据支持的结论 → 局限与改进。

观察研究无法随机对照时说明设计限制，不假装存在实验控制。数据、样本与失败记录均保留；模拟数据显式标注。报告模板提供记录字段和分析方法，不填造“实际观测结果”。

练习从读记录、诊断设计到提出改进；操作必须有可观察的检查点。答案给设计理由、预期可区分的结果与替代方案，预期结果和实际结果分开。

卡片围绕变量控制、仪器原理、误差来源或操作判据。过关区分会写报告、会设计与已完成操作；缺实际操作证据时不能宣称实验技能已掌握。
