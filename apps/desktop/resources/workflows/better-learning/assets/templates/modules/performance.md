# 活动模块：表达、操作与技能表现

选择条件：目标要求语言输出、写作、试讲、艺术表演、动作或操作能力。

嵌入章节：真实任务与受众/环境 → 完成标准 → 完整示范或可观察描述 → 技能分解 → 受控练习 → 整体表现 → 维度化反馈 → 针对性练习 → 再表现与迁移。

评价维度根据主学科选择，例如准确、连贯、得体、动作时序、稳定性、技术或表达；给每维的可观察判据及至少一个常见错误。关键风险项单独验收，其他维度不能凑分抵消。

答案区用示范产出、评价量规、可接受变体和修改建议，不强行设唯一答案。练习安排输入—尝试—反馈—重做，不能全部变成选择题。没有音频、作品、录像或真实记录时，如实限制为文字层能力验证。

卡片是行动提示与错误修正线索，掌握度按理解与实际表现分开记录。过关需独立表现及改进证据，读过步骤不代表会做。
