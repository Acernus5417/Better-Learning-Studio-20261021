# 活动模块：数据分析与证据推断

选择条件：需要处理数据、估计、解释研究结果、比较模型或评价证据。

嵌入章节：问题与目标量 → 数据来源、样本与设计 → 变量字典 → 清洗规则与缺失 → 方法及假设 → 分析/可重复计算 → 图表与不确定性 → 诊断/敏感性 → 结论及不能推出的内容。

预测任务说明训练/验证/测试分工与泄漏风险；因果任务说明设计与混淆，不能因存在回归或相关就宣称因果。演示数据须标为教学/模拟，保留分析口径，不能编造真实结果。

练习包含选法、读输出、识别误读及独立小分析。答案给结论允许范围、关键证据、诊断与限制，允许有理由的替代方法。评价数据与问题匹配、可重复性、假设和解释，而不只评价数值。

卡片连接研究问题、方法、假设、输出与误用。过关需能说明证据支持到哪里，尤其区分统计、实际与决策意义。
