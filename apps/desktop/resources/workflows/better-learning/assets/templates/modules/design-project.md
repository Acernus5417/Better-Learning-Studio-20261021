# 活动模块：设计、创作与综合项目

选择条件：需要产出方案、作品、系统、研究计划、教案或改进项目。

嵌入章节：简明任务书 → 使用者/需求 → 约束与评价标准 → 调研/依据 → 候选方案 → 取舍与原型 → 验证 → 迭代 → 交付物、过程记录与反思。

控制任务规模，使学习者能用已教知识完成；列最低可交付成果与可选扩展，不能用大项目掩盖尚未讲授的技能。任务书写清可用资源、输入、时间范围与验证方式。

参考答案给一种完整参考方案及至少一个可接受方向，说明选型理由、未满足条件和修订触发点。量规评需求满足、依据、约束、验证和迭代；不同方案可以得高评价，不能按是否像范例判断。

卡片聚焦关键设计决策或判据，完整作品留在讲义任务与附件。过关要有产出与验证证据，只有计划书不能证明系统已实现或作品已完成。
