# 活动模块：文本、史料与文献分析

选择条件：学习目标依赖原典、作品、法规、判例、访谈、档案或研究文献的解释。

嵌入章节：阅读问题 → 材料定位与必要背景 → 关键片段的短引/准确转述 → 作者、目的、体裁与受众 → 概念/结构/论证细读 → 证据链 → 互证与反证 → 可接受的替代解释 → 独立材料任务与评价。

区分原文、译文和解释；引文不可编造，保留位置与版本。原始史料、二手解释与研究结果分别标注证据地位；不能把一处短引外推为作者全部立场。

题干提供足够上下文或包内可定位材料，不让必要理解依赖未提供文本。参考答案给必须回应的线索、论证要求和不同有效读法。评价准确、相关、充分及反证处理，不以是否与范文同句评分。

卡片保存分析判据或论证结构及一个可定位实例；不要把长篇引文充当卡片。
