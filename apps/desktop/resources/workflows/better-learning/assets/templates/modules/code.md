# 活动模块：编程与调试

选择条件：目标产出含程序、脚本、查询、配置或可执行算法。

嵌入章节：输入输出契约 → 最小例子 → 表示与状态 → 实现 → 执行跟踪 → 边界与错误输入 → 调试定位 → 复杂度/资源取舍 → 独立修改任务。

写明语言/版本、依赖、运行入口及预期输出；已运行与未运行分别说明。代码先保持最小可理解，再解释需要的扩展，不用大段库调用掩盖原理。测试选能暴露契约或边界错误的输入，避免只重复示例。

独立练习使用新输入、补缺陷或新约束；参考答案包含诊断过程和可接受实现。量规评行为正确、边界、解释及与任务有关的资源指标，不按代码与范例的文本相似度评分。

卡片保留契约、关键状态与易错模式。安全/系统课程中的操作沿用课程和宿主已有授权边界，模板不会扩大实际操作权限。
