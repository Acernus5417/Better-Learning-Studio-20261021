# 活动模块：定量计算与建模

选择条件：需要计算、建立数学模型、分析参数变化或校核数量关系。

嵌入示范与练习：任务与已知 → 变量及单位 → 系统/对象边界 → 假设 → 选关系并说明理由 → 先符号后数值 → 单位、数量级、极限或守恒检验 → 结果解释与外推范围。

至少区分三类练习：同类基本应用、改变条件的变式、需要选择模型的综合。不能只换数字制造迁移题。给中间结果检查点，区分建模、代数、单位和解释错误；非物理量不强加单位。

参考答案保留方法选择与必要步骤，可接受等价方法，近似结果给精度或合理范围。卡片绑定公式/算法与适用条件，不脱离条件给孤立公式。

过关需能解释为什么能算、算得是否合理及结果意味着什么；只得最终数字不足以证明建模能力。
