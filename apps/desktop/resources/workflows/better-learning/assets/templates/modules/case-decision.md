# 活动模块：案例分析与决策

选择条件：需要在具体事实、规则、风险或资源约束下作判断。

嵌入章节：给定事实与缺失信息 → 问题/争点 → 目标与约束 → 可用规则/理论 → 备选解释或行动 → 证据与取舍 → 有条件结论 → 监测/后续动作 → 关键事实变化后的重判。

明确哪些是事实、推断、假设与价值选择；信息不足时给补证路径，不替案例编事实。法律、医疗、经营等案例沿用主学科的时效、证据与关键风险要求。

示范先完整展示一条决策链，再给独立变式。开放答案列必要判断点、可接受不同方案、导致结论变化的条件；不要只写“言之有理即可”。

卡片围绕决策判据、适用条件、反例和信息需求。过关标准包括依据、替代方案处理及行动后如何检验，而非仅选中了范例结论。
