# 艺术、设计与创作

适用：美术、音乐、舞蹈、戏剧、影视、摄影、视觉与空间设计。核心是感知、形式、技术、表达和迭代。

## 知识提取与学习路径

记录媒介、形式语言、技法、作品语境、创作意图、过程、评价维度与作品出处。区分可观察的技术特征和审美判断。路径从观察与基本技法进入有约束练习，再到创作、评议与修订；艺术史章可辅选 history。

## 小节模板

感知/创作命题 → 作品分析 → 技法分解与示范 → 有约束的小练习 → 自主方案/表现 → 多维评议 → 修订 → 作品与过程反思 → 下一次练习。

演奏/表演/技法选 performance，创作方案选 design-project，艺术评论选 text-evidence。示范作品缺失时不能虚构“已展示”；审美评价须说明标准与作品证据，不以个人偏好代替技术反馈。

## 卡片与过关证据

卡片是技法提示、观察判据或创作决策，配适用情境与常见失误。评价技术控制、表达意图、结构与修订证据，允许多种风格；给学生可执行的改进动作，不只打主观总分。

## 微型示范

主题“视觉层级”：比较信息同等突出与层级明确的布局，逐项解释对齐、对比和留白；让学生为同一内容制作两种层级方案，并用阅读顺序与任务目标说明取舍。
