# 历史、考古与区域史

适用：通史、专题史、思想史、考古及历史材料课程。核心是时序、语境、史料批判与有证据的解释。

## 知识提取与学习路径

记录时间、地点、人物/制度、事件链、材料出处与形成时间、作者立场、史料类型、解释争议和证据缺口。区分当时人的说法、可核事实与后来的史家解释。路径先建立时空坐标，再学习材料互证、因果和比较。

## 小节模板

历史疑问 → 时间线与背景 → 史料短摘或转述及出处 → 作者/目的/受众 → 多材料互证 → 原因与后果的解释 → 反证与替代解释 → 独立材料题 → 论证量规与修正。

通常选 text-evidence；档案统计选 data-analysis。不能用后见之明替代当时行动者视角，不把时间先后直接等同因果，不虚构原始史料或引文。

## 卡片与过关证据

卡片围绕事件链、制度变化、解释争议或史料方法，保留时空与证据。年表用于定位，掌握还需能说明“依据什么这样解释”。答案给核心证据和可接受解释，不只给背诵段落。

## 微型示范

主题“解释一次制度改革”：先建改革前后时间线，再比较官方文本与另一类材料的用途；让学生分别提出动因与实际效果的判断，标明证据支持到何处、尚不能确定什么。
