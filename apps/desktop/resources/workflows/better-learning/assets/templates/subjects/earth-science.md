# 地球、地理与环境科学

适用：地质、地理、气象、海洋、环境、资源与空间分析。核心是时空尺度、过程耦合和多源证据。

## 知识提取与学习路径

记录位置、尺度、时间、边界、物质/能量过程、地图图例与坐标、数据分辨率及不确定性。区分局地与区域、天气与气候、相关与机制。路径由空间与时间表征进入过程，再到系统耦合与区域问题。

## 小节模板

区域或环境问题 → 地图/剖面/时间序列读图 → 尺度与背景 → 过程链 → 多源证据互证 → 替代解释 → 场景预测或治理方案 → 外推边界 → 评价与回看。

观测选 lab，空间/气候数据选 data-analysis，规划与治理选 design-project。地图缺比例尺、投影或数据时间时注明限制，不能从示意图读出没有依据的精确数值。

## 卡片与过关证据

卡片包含“过程—时空条件—证据—适用边界”；分类卡保留判别依据。考核读图、区域比较与因果链，方案须解释尺度、约束与验证指标。

## 微型示范

主题“城市热岛”：区分观测温差、测点背景和机制解释，再比较地表覆盖与时间段。让学生提出能区分下垫面效应和测点偏差的比较设计，不能凭一幅温度图完成因果归因。
