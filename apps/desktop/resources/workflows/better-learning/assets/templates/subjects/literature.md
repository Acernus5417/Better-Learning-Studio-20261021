# 文学、文本与文化阐释

适用：文学、语文阅读、比较文学、文艺理论、文化与媒介文本分析。核心是细读、形式、语境和有证据的阐释。

## 知识提取与学习路径

记录作品/篇章定位、叙述声音、体裁、意象、结构、修辞、关键语句、历史语境和不同解释。区分作者、叙述者、人物与读者推断。路径先理解字面内容和形式，再建立解释与文本证据，最后比较与写作。

## 小节模板

阅读疑问 → 必要语境 → 关键片段细读 → 形式如何产生意义 → 提出阐释 → 文本支持与反证 → 替代读法 → 独立分析/短文 → 评价、改写与反馈。

细读选 text-evidence，写作/表达选 performance。短引须标原文与版本，不能把概括伪装成引文；不能把“主题思想”唯一句当作所有问题的答案。

## 卡片与过关证据

卡片按分析概念、形式手法或关键解释问题组织，带可定位实例与误读辨析。开放答案列证据和推理要求，允许多种合理阐释；评价文本准确、形式意识、证据与论证连贯。

## 微型示范

主题“不可靠叙述”：比较叙述者陈述与文本中的冲突线索，再提出可信度判断；让学生用另一片段支持或修正判断。仅凭“不喜欢该人物”不能构成文本证据。
