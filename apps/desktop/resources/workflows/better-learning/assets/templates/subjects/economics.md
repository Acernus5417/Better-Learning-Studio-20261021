# 经济学与经济政策

适用：微观、宏观、国际、发展、公共经济与理论金融课程。核心是激励、约束、边际、均衡与政策取舍。

## 知识提取与学习路径

记录行为主体、偏好/技术/资源约束、制度背景、变量、均衡条件、比较静态和经验依据。区分恒等式、行为关系、模型预测与规范判断。路径先掌握主体与约束，再建立均衡，最后考察冲击、福利和实证检验。

## 小节模板

经济问题 → 主体与激励 → 模型假设 → 图形与符号一致解释 → 均衡与变化机制 → 受益/受损与效率判断 → 证据及模型边界 → 政策或情境比较 → 论证与反馈。

模型章选 quantitative，实证章选 data-analysis，政策章选 case-decision。不能把“其他条件不变”的结论无条件应用到现实，也不把价值判断写成纯技术结论。

## 卡片与过关证据

卡片围绕机制或判据，包含假设、比较方向、图像和反例。考核解释冲击通过什么机制起作用、何时结论改变；政策题按目标、约束、分配影响与证据评价。

## 微型示范

主题“税负归宿”：从法定纳税人与实际负担的区别切入，用供需弹性解释分担；让学生在供给弹性改变后重画图并解释福利变化。只记“谁缴税谁承担”不能过关。
