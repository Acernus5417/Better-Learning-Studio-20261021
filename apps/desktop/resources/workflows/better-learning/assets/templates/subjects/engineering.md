# 工程与技术

适用：机械、电气、电子、自动化、土木、交通、能源、化工、建筑技术与制造。核心是需求、约束、模型、方案和验证。

## 知识提取与学习路径

记录系统功能、输入输出、接口、图纸/电路/流程、假设、设计约束、性能指标、公差与失效模式。区分理论结果、经验设计和规范要求；规范版本不明则标注。路径由部件原理进入系统分析，再到参数设计、校核与取舍。

## 小节模板

工程任务 → 需求与验收指标 → 系统及接口图 → 模型假设 → 选方案与参数 → 分析/仿真/试验 → 性能与极限校核 → 故障或约束变化 → 方案修正与反馈。

分析章选 quantitative，设计章选 design-project，试验章选 lab；带软件控制的内容可选 code。不能只给最终尺寸或参数，不解释选型和校核。

## 卡片与过关证据

卡片按原理、选型判据、设计步骤或故障诊断组织；公式带边界，流程带检查点。独立任务应给明确约束与验证证据，评价可行性、指标满足与理由，允许不同有效方案。

## 微型示范

主题“低通滤波设计”：先给截止频率与负载条件，再建立模型、选参数并检查响应；改变负载让学生解释原方案何处失效。过关包含指标与模型条件，不能只代公式得到元件值。
