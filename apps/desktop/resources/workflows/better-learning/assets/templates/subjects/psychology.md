# 心理学与行为科学

适用：认知、发展、社会心理、人格、实验心理与心理测量。核心是构念、操作化、研究设计及证据限制。

## 知识提取与学习路径

记录理论构念、定义、操作指标、研究范式、样本、设计、效应及替代解释；区分理论、观察与作者的外推。路径先理解构念，再读研究与比较理论，最后设计任务和评价证据。

## 小节模板

行为现象 → 构念及竞争解释 → 操作化与研究范式 → 设计/结果 → 理论解释 → 混淆因素与外推范围 → 新情境预测 → 独立评价或小设计 → 量规与反馈。

实验选 lab，研究结果选 data-analysis，理论阅读选 text-evidence。不能从个案或相关性直接诊断人格、心理障碍或推出因果；举例不替代研究证据。

## 卡片与过关证据

卡片包含构念、操作指标、典型范式与易混理论。考核能否解释指标为何代表构念、识别混淆和选择区分理论的证据；不把研究结论记忆当作会做研究。

## 微型示范

主题“工作记忆”：区分概念定义与一种测量任务，再解释任务表现可能受哪些因素影响；让学生提出对照区分注意困难与存储负荷。过关需说明指标、解释及其限制。
