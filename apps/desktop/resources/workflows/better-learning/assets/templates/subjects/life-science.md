# 生命科学与生物技术

适用：细胞、分子、遗传、生理、生态与生物技术。核心是层级结构、机制、调控与实验支持。

## 知识提取与学习路径

记录结构层级、输入输出、因果机制、调控与反馈、时间尺度、适应解释、证据及适用物种/条件。区分机制解释与功能描述，不以“为了……”代替因果。路径由组成与层级进入过程，再到调控、扰动和系统联系。

## 小节模板

生物现象 → 层级与结构定位 → 过程分步图 → 机制与调控 → 支持证据 → 扰动后预测 → 对照/替代机制 → 独立情境题与理由 → 错误诊断。

实验篇选 lab，组学/群体数据篇选 data-analysis，涉及机制的量化模型可选 quantitative。彩图中的方向、区室与时序必须进入文字解释。

## 卡片与过关证据

卡片围绕一个机制、结构功能关系或实验判据，保留条件、例外与混淆概念。考核机制复述、改变条件后的预测和证据判断；只有名称记忆不能证明会解释实验。

## 微型示范

主题“酶活性”：用温度变化引出反应速率与结构稳定性的不同作用，比较条件控制后的曲线；让学生设计区分“底物不足”与“酶失活”的对照。过关需解释曲线并说明对照能排除什么。
