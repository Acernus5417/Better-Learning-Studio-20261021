# 计算机、软件与信息系统

适用：程序设计、数据结构、算法、系统、网络、数据库、软件工程、信息安全与人工智能。核心是表示、执行过程、抽象和可验证行为。

## 知识提取与学习路径

记录输入输出契约、数据表示、状态变化、不变量、前后置条件、算法步骤、复杂度、接口与失败情形。区分抽象语义、语言实现与环境版本。路径先能跟踪小例子，再解释原理，随后独立实现、调试与权衡。

## 小节模板

计算任务 → 最小输入输出 → 表示与状态跟踪 → 核心规则/算法 → 完整可运行示例或伪代码 → 正确性理由 → 边界与失败输入 → 独立实现/调试 → 资源与设计取舍。

实现章选 code，正确性章选 proof，机器学习与评估选 data-analysis，系统设计选 design-project。声称可运行的代码需写明环境与实际验证状态；不能把解释性伪代码冒充已运行程序。

## 卡片与过关证据

卡片包括契约、最小例子、关键状态或不变量、适用场景和常见错误。考核跟踪、修改、调试与迁移；给测试输入及预期行为，不能只让学生复制代码或背复杂度结论。

## 微型示范

主题“二分查找”：明确区间约定并逐步跟踪，再解释区间缩减与终止；让学生检查空数组、单元素和不存在目标。过关需维持自己的区间不变量并解释边界输入。
