# 通用回退：按知识与证据形式设计

适用于尚未选学科的旧课程或确实无法归类的交叉课程。记录回退原因，不称为已经完成学科适配。

- 知识提取：保留概念、方法、证据、条件、例外与材料中的独立任务；明确哪些是事实、解释或操作。
- 路径：以能完成的任务建立先修关系，不能只重排目录。
- 小节：问题 → 必要知识 → 解释与证据 → 完整示范 → 独立任务 → 反馈与修正 → 来源。
- 卡片：一个能独立检验的概念或技能，给判据、具体案例、错误和检索题。
- 验收：学习者能解释依据并在变化情境下完成任务；无公式、实验或唯一答案时不生造对应栏目。

缺少匹配方法时，从活动模块补足，并在质量报告说明采用的解释方法与验收证据。
