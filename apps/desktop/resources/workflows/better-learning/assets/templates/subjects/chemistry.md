# 化学与材料化学

适用：无机、有机、分析、物理化学及材料化学。核心是宏观现象、微观结构与符号表达的相互解释。

## 知识提取与学习路径

记录结构、组成、反应物与产物、条件、守恒、热力学与动力学区别、机理证据、竞争反应和表征结论。化学式、电荷、立体信息、平衡与反应箭头不得混写。路径先建立粒子与键合模型，再解释性质、反应与分析方法。

## 小节模板

现象或合成/检测任务 → 宏观观察 → 微观结构 → 化学符号与守恒核对 → 条件与机理 → 竞争解释/副反应 → 完整判断或计算示范 → 改变条件的预测 → 证据与反馈。

实验章选 lab，浓度、平衡与动力学计算选 quantitative；机理箭头需解释电子或粒子变化依据。实验操作仅依据可靠材料描述，不把猜测的操作条件写成教材事实。

## 卡片与过关证据

卡片按“结构—性质”“反应类型—条件—限制”或“分析信号—判据”组织；避免把孤立方程式当完整知识。自测需解释为何生成此产物、何种条件改变结论，计算须核对物料、电荷与单位。

## 微型示范

主题“催化与平衡”：先比较到达平衡的快慢和最终组成，再解释催化路径与速率。让学生分别判断“更快达到平衡”和“平衡向产物移动”，用证据纠正将动力学与热力学混为一谈的错误。
