# 体育、运动与动作技能

适用：体育理论、运动技能、训练、体能与运动学习。核心是动作阶段、感知反馈、负荷、恢复与表现。

## 知识提取与学习路径

记录动作目标、阶段、关键姿态/时序、环境条件、负荷指标、恢复、常见错误与观察方法。区分动作描述、力学解释与训练建议。路径从动作感知与基础能力进入分解练习，再整合、情境运用与反馈。

## 小节模板

运动任务 → 动作阶段与观察位置 → 关键提示及原理 → 分解练习 → 整体练习 → 可观察错误与修正 → 情境变化 → 记录、恢复与复测。

技能选 performance，运动生理实验选 lab，表现数据选 data-analysis。训练量依据给定人群和资料条件，不从统一模板推定个体适宜强度；文字理解、录像观察与真实动作表现分别记录。

## 卡片与过关证据

卡片围绕一个动作关键点、错误诊断或训练原则，带观察标准与修正练习。过关使用动作质量、稳定性和情境表现，关键风险项独立处理；不能用术语笔试代替动作掌握。

## 微型示范

主题“投篮动作学习”：把准备、发力、出手和随势分开观察，针对具体失误给一个练习；用多次表现而非单次命中评价动作变化。没有实际动作记录时只判理论理解。
