# 医学、护理、药学与公共卫生

适用：基础医学、临床教学、护理、药学、营养与公共卫生。核心是机制、证据、风险、优先级及操作判断。

## 知识提取与学习路径

记录正常结构/功能、病理链、表现、鉴别线索、检查意义、干预机制、禁忌与监测，保留材料的适用人群、剂量单位与指南时点。区分教学情境、诊断证据与行动建议。路径由正常到异常，由机制到识别，再到决策和随访。

## 小节模板

教学病例/健康问题 → 关键表现 → 正常与病理机制 → 问题表述 → 鉴别及证据 → 优先级与决策理由 → 风险、监测与升级条件 → 病例变化/操作自测 → 解析与反馈。

病例选 case-decision，操作选 performance，试验与人群证据选 data-analysis。真实医疗问题超出教学材料时，不能把教学示例泛化为针对个人的诊疗结论；对关键单位与条件按材料逐项复核。

## 卡片与过关证据

卡片按机制、鉴别判据、药物作用条件或操作检查组织。考核区分关键线索、解释证据、选择下一步与识别升级条件；关键风险项单独过关，不能用总分抵消。文字答题不证明已具备临床操作资质。

## 微型示范

主题“贫血分类”：从给定症状和检验资料提出问题，先区分形态分类与病因判断，再说明还需要的证据。过关要求给出有条件的鉴别过程，不能仅凭一个指标宣布病因。
