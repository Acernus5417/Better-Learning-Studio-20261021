# 法学与规范适用

适用：法理、实体法、程序法、案例与规范分析。核心是争点、规则效力、要件、事实认定和论证。

## 知识提取与学习路径

记录法域、时点、规范层级、来源版本、构成要件、例外、举证责任、程序与救济；区分法律文本、解释立场、判决事实和作者评论。路径先掌握基本关系与规则，再识别争点、涵摄事实、处理冲突与论证。

## 小节模板

教学案例事实 → 争点 → 适用规范及效力/时点 → 要件拆分 → 事实与要件对应 → 反方论证及例外 → 有条件的结论与救济 → 改变关键事实的自测 → 评分点与反馈。

案例选 case-decision，条文/判决阅读选 text-evidence。只分析已给定事实，不擅自补案件事实。资料过时不默认为现行规则，课程学习示例与真实个案建议要分清范围。

## 卡片与过关证据

卡片保留规则要件、例外、时空效力与适用争点。论述答案给可接受立场、必要论据和影响结论的事实，不把争议题写成唯一标准句。掌握证据为完整的争点—规范—涵摄—结论链。

## 微型示范

主题“合同成立与生效”：先分别核对成立条件和效力条件，再对给定案例分开论证；改变一个事实观察结论。过关需解释两种判断的区别，并说明所用规则适用的法域与材料时点。
