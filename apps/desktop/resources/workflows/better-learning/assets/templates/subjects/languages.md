# 语言学习、语言学与翻译

适用：母语/外语、听说读写、语音、词汇、语法、翻译与语言学。语言运用重情境和产出，语言学理论章重分析与证据。

## 知识提取与学习路径

记录形式、意义、使用情境、语体、搭配、语音/书写变化、规则限制和真实例句定位。区分规则解释、频率倾向与得体性。路径由可理解输入到辨认、受控使用，再到有目的表达与反馈修订；语言学章按概念和分析方法依赖组织。

## 小节模板

交际/分析任务 → 可理解输入与示范 → 注意目标形式 → 形式—意义—语用解释 → 对比与受控练习 → 自主输出/分析 → 标准与纠错 → 修改再做 → 新情境迁移。

听说写译选 performance，文本/语言现象分析选 text-evidence；理论计算可另配模块。没有音频时不能声称完成听力或发音测评；翻译按功能、受众和语境评价，不机械要求逐字唯一译法。

## 卡片与过关证据

卡片按一个可使用的表达、规则对比或分析判据组织，保留语境、搭配、正反例和检索提示。考核准确、流利/连贯和得体性，理解与产出分开记录，不能以选择题成绩证明能交际。

## 微型示范

主题“请求表达”：提供对象、目的和关系明确的情境，比较表达的语气，再要求学生对同伴与教师分别改写并说明选择。过关需形式正确且符合情境，答案允许多种表达。
