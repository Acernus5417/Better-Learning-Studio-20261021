# 哲学、伦理与思想论证

适用：哲学、伦理学、认识论、思想理论及论证分析。核心是概念区分、论证重建、反例和回应。

## 知识提取与学习路径

记录问题、术语在作者语境中的含义、前提、结论、推理形式、隐含假设、反驳及回应；区分立场介绍与作者的支持论证。路径先理解问题和区分，再重建论证，最后检验、回应与形成自己的立场。

## 小节模板

思想难题 → 概念区分 → 立场与最强论证 → 逐项前提 → 反例/反驳 → 可能回应 → 比较立场的代价 → 独立论证 → 评价与修订。

原典选 text-evidence，形式论证选 proof，应用伦理选 case-decision。合理性与有效性、事实与规范不能混淆；不能用作者声望替代论证。

## 卡片与过关证据

卡片包含问题、关键区分、论证骨架、反驳和适用边界。考核准确重建对方观点、判断推理、提出相关反例及回应；允许不同立场，以准确、公平和论证质量评价。

## 微型示范

主题“结果与义务”：对同一教学情境分别重建两种判断，显式列出前提，再要求学生提出各自最难回应的反例。只选边站不能过关，需解释推理与代价。
