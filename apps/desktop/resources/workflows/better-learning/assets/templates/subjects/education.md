# 教育学、教学与学习设计

适用：教育理论、课程、教学法、教育技术、特殊教育与教师训练。核心是学习者、目标、活动、评价及证据驱动的改进。

## 知识提取与学习路径

记录理论主张、适用学习者、学习机制、教学条件、活动设计、评价依据及研究限制。区分教学建议、经验案例与有研究支持的结论。路径从学习与发展机制进入课堂诊断、设计、实施和反思。

## 小节模板

学习/课堂问题 → 学习者与目标 → 理论机制 → 活动与支架 → 评价任务及标准 → 示例课段 → 学习证据与诊断 → 调整方案 → 微型教学/独立设计与反馈。

教案选 design-project，试讲选 performance，课堂问题选 case-decision，研究证据选 data-analysis。不能只写丰富活动而不解释为何有助于目标，也不能将学生满意度视为掌握证据。

## 卡片与过关证据

卡片按一个教学决策或学习机制组织，包含适用对象、设计依据和误用。评价目标—活动—评价是否对齐、支架是否回应困难、修改是否有学习证据；文本教案与真实教学表现分开记录。

## 微型示范

主题“形成性评价”：先给一个常见误解，设计能暴露该误解的题目，再依据两类回答安排不同反馈。过关需说明回答证据怎样改变下一步教学，不能只有一份小测卷。
