# 数学与形式科学

适用：代数、分析、几何、离散数学、逻辑及形式理论；以定义、条件、结构和演绎为核心。数据推断另选 statistics，物理解释另选 physics。

## 知识提取与学习路径

保留定义的量词与对象域、命题条件和结论、等价关系、证明关键步、反例及不同解法。区分定义、定理、推论与经验做法。路径按概念依赖组织，先让学生识别对象，再用判据与定理，最后处理证明、综合和抽象迁移。

## 小节模板

问题或反直觉例子 → 图形/数值直觉 → 正式定义与符号 → 逐步推理 → 定理条件核对 → 正例与边界反例 → 一题完整解答 → 条件变化的独立练习 → 错因与回看。

证明需要解释“为什么这一步可做”，计算需要说明“为什么选这个方法”；不能把计算熟练视为会证明。证明篇选 proof，计算或建模篇选 quantitative。不要求每个定义都附一份虚构证明。

## 卡片与过关证据

卡片绑定命题与条件、最小判据、反例和选择方法的线索。自测至少区分会识别、会使用与会迁移；证明题给逻辑评分点和允许的替代路径。正确结论但关键推理缺失不能判证明通过。

## 微型示范

主题“可导与连续”：先观察角点，再明确“可导 ⇒ 连续”的方向，演示利用导数定义推出连续；让学生用绝对值函数检验逆命题。过关需分别说明原命题、逆命题及反例为何成立，不能只背一句口诀。
