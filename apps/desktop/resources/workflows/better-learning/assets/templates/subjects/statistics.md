# 统计、数据科学与研究测量

适用：概率统计、推断、计量方法、数据分析与测量。核心是随机性、设计、估计、不确定性和可重复解释。

## 知识提取与学习路径

记录总体/样本、参数/统计量、抽样或实验设计、数据生成假设、估计目标、模型条件、诊断、区间与偏差。区分描述、预测和因果。路径先认识变异与设计，再选择方法、计算、诊断和解释；推导可用 mathematics 辅助。

## 小节模板

研究问题与目标量 → 数据与设计 → 方法及假设 → 小数据演算/模拟 → 输出解释 → 假设诊断与不确定性 → 敏感性/替代方法 → 独立分析任务 → 可重复记录与反馈。

数据操作选 data-analysis，理论推导选 proof 或 quantitative，实现选 code。示例数据须标明模拟/教学数据，不伪装成真实调查；不能以统计显著代替实际意义或因果证据。

## 卡片与过关证据

卡片绑定“问题—目标量—方法—假设—输出解释—失效情形”。考核选法与解释而非只按计算器；答案应允许有理由的替代方法，报告不确定性和不能推出的结论。

## 微型示范

主题“均值置信区间”：先说明估计的对象与抽样过程，再演示计算和重复抽样解释；让学生辨析区间、个体范围与参数概率的不同说法。过关需解释结果并指出设计与假设限制。
