# 农林、动物与食品科学

适用：农学、园艺、林学、畜牧、兽医教学、水产、食品科学与农业资源。核心是生物过程、生产系统、环境条件与质量控制。

## 知识提取与学习路径

记录物种/品种、生长阶段、环境、生产流程、投入产出、病害/质量指标、试验条件与季节区域限制。区分机制、经验措施和规范要求。路径由生物与环境基础进入过程管理，再到诊断、干预和评价；兽医临床章辅选 medicine。

## 小节模板

生产/健康/质量问题 → 对象与环境 → 机制及流程 → 观测指标 → 方案与操作条件 → 对照/监测 → 成本、产量或质量取舍 → 变化情境 → 记录与反馈。

试验选 lab，田间/生产数据选 data-analysis，生产方案选 design-project，诊断决策选 case-decision。不能把某地区、某品种或某阶段结果无条件推广；操作剂量和加工参数保留材料单位与适用条件。

## 卡片与过关证据

卡片按“对象—条件—机制/指标—措施—监测”组织。考核诊断所需证据、条件变化后的方案修订与质量验证；经验口诀必须补作用条件和例外。

## 微型示范

主题“缺素与病害辨析”：先记录症状部位、时序和环境，再提出候选解释与补充检测；让学生设计比较或取样方案。过关需说明哪些证据可区分原因，不能只凭一张叶片描述下结论。
