# 物理与天文

适用：力学、电磁学、热学、光学、近现代物理、天文学。核心是现象、理想化模型、守恒与可检验预测。

## 知识提取与学习路径

记录系统边界、参考系、物理量与单位、定律适用尺度、近似、实验事实、图像含义。区分观察、模型和推导结果。路径由现象与量的定义进入模型，再到多表征转换、预测和检验；不能只按公式难度排序。

## 小节模板

可描述的现象 → 选择系统与画图 → 列假设及量 → 选定律并解释理由 → 符号推演 → 数值/图像结果 → 单位、极限和数量级检查 → 模型失效情境 → 独立变式与答案。

定量章选 quantitative；实验章选 lab，处理测量数据时再选 data-analysis。图示应有方向、坐标与参照，不能让学生仅靠背图得出结论。

## 卡片与过关证据

一卡包括规律、适用条件、物理解释、典型图像和误用反例。考核解释题、建模题和检验题；数值正确但系统或假设错误要反馈到建模步骤。实验结论须能追溯数据与不确定性。

## 微型示范

主题“自由落体”：先明确忽略空气阻力与重力近似不变，再选竖直方向并推演位移；让学生解释纸片为何偏离模型，并提出可检验的对照。过关同时要求会计算和会说明模型边界。
