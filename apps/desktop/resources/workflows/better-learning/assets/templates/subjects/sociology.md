# 社会学、政治学与社会研究

适用：社会学、政治学、人类学、传播、社会工作与社会研究方法。核心是概念、机制、制度情境与多种证据。

## 知识提取与学习路径

记录分析层次、概念操作化、理论主张、机制、制度/历史情境、证据类型、研究设计和反方解释。区分事实陈述、因果解释与价值立场。路径由概念与问题进入理论比较，再到材料解释和研究设计。

## 小节模板

社会问题 → 概念与分析层次 → 理论机制 → 定量/质性证据 → 竞争解释 → 情境与外推边界 → 案例或研究设计 → 独立论证 → 证据量规与反馈。

文献/访谈选 text-evidence，调查选 data-analysis，政策/介入选 case-decision。保留不同立场的依据，不能用一个案例证明所有群体，也不能把评价立场藏在概念定义中。

## 卡片与过关证据

卡片按概念、机制或理论比较组织，含层次、证据和边界。开放题评概念准确、机制清楚、证据匹配、反方处理与论证连贯；支持不同有根据的结论。

## 微型示范

主题“社会资本”：先明确不同理论对概念的使用，再比较个体网络与群体层面的指标；让学生解释一个案例，并指出哪种证据能区分网络资源与收入因素的影响。
